自定义 osu! 皮肤放在这里，每个皮肤一个文件夹。例如：
Skins/My Skin/skin.ini
Skins/My Skin/hitcircle.png

预览工具栏 → 皮肤：选择 stable、lazer 或自定义皮肤。
可在菜单里导入 .osk，也可把 .osk 拖入程序窗口。重新打开皮肤菜单会扫描此文件夹；
修改当前皮肤的文件后，点击“刷新皮肤”重新加载。缺少的素材回退到 stable 默认皮肤。

无论源码运行还是绿色版，均使用程序 exe 所在目录的 Skins。
程序自带的默认皮肤和 lazer 素材打包在 SbStudio.Resources.dll 中，不在此文件夹里展开。
