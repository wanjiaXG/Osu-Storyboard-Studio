Sources: osu!lazer (ppy/osu) Skinning/Argon and osu! resources from the installed game.
The normal/soft/drum WAV samples and spinner WAV samples are the original Argon gameplay sounds,
extracted unchanged from osu.Game.Resources.dll. Their terms are in osu-resources-LICENCE.txt.
The taiko-soft/normal/drum/strong WAV samples are also unchanged Argon resources. Taiko selects
softness by volume (below 60, 60-89, or 90+) and uses the strong bank for large notes.
approachcircle and repeat-edge-piece are the textures used by DefaultApproachCircle and ArgonReverseArrow.
spinner-glow is the shader input used by ArgonSpinnerProgressArc (retained as a resource reference).
The circular pieces, borders, gradients and spinner arcs are drawn geometrically, as in Argon.
Font Awesome 5 Free Solid supplies ChevronRight, AngleRight, AngleDoubleRight and Mania's AngleDown.
The packaged font pages contain these icons. Attribution: Font Awesome by Fonticons, Inc.
See FontAwesome-LICENCE.txt and osu-resources-LICENCE.txt for asset terms; osu-MIT-LICENCE.txt for source attribution.

Torus Bold is not included because it requires a commercial distribution licence.
The application uses a locally available bold system font for the numbers; no installed game is required.
Argon's font size of 52 is measured using the font's original size, rather than the cropped glyph height.
