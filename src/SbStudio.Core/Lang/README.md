# 界面语言

内置语言：`en`、`zh-Hans`、`zh-Hant`、`ja`、`ko`、`ru`、`es`、`th`、`pt-BR`、`it`、`nl`、`fr`、`de`、`lt`、`id`、`vi`。

每个 JSON 文件以英语 `en.json` 为键名和参数格式的基准，目前每种语言有 894 条界面文本。新增的 14 种语言为初版翻译，已修订主要菜单和编辑术语，并校验所有键名、参数和命令示例；专业长说明仍可由母语使用者继续校对。

- `$name` 使用语言自己的名称，显示在“视图 → 语言”中。
- `$font` 可指定 Windows 字体文件名，用来补全主字体缺少的文字。日语使用 `meiryo.ttc`，韩语使用 `malgun.ttf`，泰语使用 `tahoma.ttf`，繁体中文使用 `msjh.ttc`，越南语使用 `segoeui.ttf`。字体由系统提供，不随项目复制。
- 保留 `{0}`、`{1:0.###}` 等完整格式参数、换行、快捷键和故事板命令字母。不要翻译 `Sprite,Background,TopLeft` 等语法。
- 文件自动嵌入 Core，并复制到程序旁的 `lang/`，不需要逐个修改项目文件。用户仍可在 `lang/` 中覆盖或添加翻译。
- 缺失条目回退到英语；内置文件必须完整，运行本地化测试可检查覆盖和参数。
- 系统区域自动匹配对应语言；`zh-Hant`、香港和澳门匹配繁体中文，`zh-Hans` 匹配简体中文。
- 兼容旧设置与区域代码 `zh-CN`、`zh-TW`，分别映射到 `zh-Hans`、`zh-Hant`。旧文件名的外部语言包仍可读取，不会增加重复的语言；新旧文件同时存在时，新文件名优先。
